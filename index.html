Who are We

One Platform. One Search. One Legacy Reclaimed.

LehumoLago is a South African mobile platform designed to help citizens instantly search, verify, and reclaim unclaimed financial assets owed to them. Using a simple ID-number-based search, we consolidate official public records into one accessible app and guide users through a fast, transparent claim process.

How It Works

Reclaim in 3 Simple Steps.

1. User Search Once

• User enters basic information and ID Number
• Then press Find Match

2. Search and Find Match in Few Minutes

• Platform searches for a match and delivers results in a few minutes

3. Match Found? Download Self-Help Claim Kit

• Once a match is found, user can download a self-claim kit
• Chatbot guides step-by-step through the entire claims process
